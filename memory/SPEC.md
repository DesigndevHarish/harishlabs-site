# Harish Kumar Portfolio — Living Spec

## Product

Single-page, dark-first personal portfolio for Harish Kumar, Data Engineer / Data Analytics Professional. It explains the full journey from raw events through ingestion, cloud storage, warehousing, transformation, analytics, and business decisions.

## Key flows

- Sticky navigation scrolls to About, Stack, Projects, Architecture, Analytics, and Contact.
- Stack category tabs reveal grouped technology chips.
- Project cards select a project and case-study buttons scroll to the flagship case study.
- Architecture nodes are clickable and reveal the selected component's explanation.
- Dashboard tabs switch between four interactive BI previews, questions, and KPI sets.
- Mobile navigation opens as a compact menu.

## Data and integrations

- Portfolio content is static and intentionally demo-oriented; no live external APIs are connected.
- GitHub, project repositories, email, and WhatsApp are connected to Harish's supplied destinations; LinkedIn is intentionally omitted for now and the resume link remains open for later.
- Existing FastAPI status endpoints remain available under `/api` for template connectivity smoke checks.

## Visual system

Dark charcoal surfaces, off-white editorial typography, electric cyan accents, JetBrains Mono technical labels, thin borders, subtle data-flow animation, responsive vertical architecture flow on mobile, and no skill percentage bars or fake metrics claims.

## Auth / roles

No authentication or gated areas.
